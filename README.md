# 📊 C# Finansal CRM Uygulaması

Bu proje, kişisel veya kurumsal finansal süreçlerin yönetilmesi amacıyla geliştirilmiş bir masaüstü CRM uygulamasıdır.

## Proje Amacı

Banka hesap hareketlerini, kategorize edilmiş harcamaları ve fatura işlemlerini tek bir merkezden takip etmek. Relasyonel veritabanı (MS SQL Server) üzerinde tablo ilişkilerinin nasıl kurulduğunu ve C# masaüstü formları ile nasıl entegre edildiğini simüle eder.

## Temel Özellikler

* **Banka Yönetimi:** Banka hesap bakiyeleri ve son hesap hareketlerinin (giriş/çıkış) takibi.
* **Harcama Kategorileri:** Giderlerin belirli alanlara (Fatura, Market, Eğitim vb.) ayrılarak listelenmesi ve kaydedilmesi.
* **İlişkisel Veritabanı Mimarisi:** Tablolar arası kurulan Primary Key (PK) ve Foreign Key (FK) bağlantıları ile tutarlı ve güvenli veri yönetimi.

## Teknoloji Yığını

* **Programlama Dili:** C# (.NET)
* **Veritabanı:** MS SQL Server
* **Arayüz:** Windows Forms
